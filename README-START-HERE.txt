CAMBODIA TRANSPORTATION — SEO LANDING PAGES

This ZIP adds three separate search-friendly service pages without replacing your current homepage.

FOLDERS TO UPLOAD TO THE SAME REPOSITORY ROOT:
- airport-transfers-siem-reap/
- private-driver-cambodia/
- siem-reap-to-phnom-penh/

Also replace sitemap.xml with the included sitemap.xml.

IMPORTANT:
1. Back up your current sitemap.xml first.
2. Do NOT replace or delete your existing root index.html with this package.
3. Upload the three complete folders, keeping each folder name and its index.html.
4. Upload the included sitemap.xml to the repository root, replacing the existing sitemap.
5. Commit changes and wait for deployment.
6. Test each new URL and the sitemap:
   https://cambodiatransportation.com/airport-transfers-siem-reap/
   https://cambodiatransportation.com/private-driver-cambodia/
   https://cambodiatransportation.com/siem-reap-to-phnom-penh/
   https://cambodiatransportation.com/sitemap.xml
7. In Google Search Console, resubmit the sitemap and inspect/request indexing for each new URL.

Pricing note:
The Siem Reap–Phnom Penh page uses the previously provided reference fares of $70 private car and $90 private van one way. Verify they are still correct before publishing.

The pages link back to the main homepage for booking because the exact booking-form anchor was not verified. Adjust the links if your booking page has a confirmed direct URL.

SEO does not guarantee a particular ranking. Give Google time to crawl the pages and monitor Search Console.
