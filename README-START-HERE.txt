CAMBODIA TRANSPORTATION — GOOGLE INDEXING PACKAGE

WHAT TO DO
1. Back up the current files in your GitHub repository first.
2. Open the repository used to publish https://cambodiatransportation.com/.
3. Upload these three files to the repository root (the main folder):
   - index.html
   - robots.txt
   - sitemap.xml
4. Commit the changes and wait for the website to publish.
5. Check these URLs in your browser:
   https://cambodiatransportation.com/robots.txt
   https://cambodiatransportation.com/sitemap.xml
6. In Google Search Console, submit sitemap.xml, inspect the homepage,
   run the live test, then click Request indexing if offered.

IMPORTANT
- Keep Camvdo.mp4 in the same location as the existing homepage expects.
- The HTML is self-contained for its embedded photos; the video file is
  separate and is not included in this ZIP.
- Upload these files to the repository/deployment that serves your custom
  domain. Uploading to a different repository will not change the domain.
- These settings help Google crawl the site but cannot guarantee indexing.
