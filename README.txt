Cambodiatransportation website

Files:
- index.html: existing website with only an added low-volume background music player
- Camvdo.mp4: service video used by the homepage
- cambodiatransportation-logo.webp: site logo and favicon
- logo-all-destinations.png, logo-city-ride.png, logo-intercity.png: supporting website graphics
- music-track-3.m4a: ចំបុីសៀមរាប (plays first)
- music-track-1.m4a: មនអសអលយ (plays second)
- music-track-2.m4a: ផតជយបណតលចតត (plays third)

The music player tries to autoplay at 12% volume and plays the three tracks in the order above, then repeats continuously. Browsers may block audible autoplay until the visitor clicks Play. The floating music control lets visitors turn music on or off.

Upload all files in this folder to the same directory in your GitHub Pages repository. Keep all media files alongside index.html.
